# Construhogar Ingeniería Civil

Construcción, remodelación y servicios locativos en Marinilla, Antioquia · Carrera 34.

El cotizador avanza por tres pantallas: nombre; requerimiento; fecha y hora preferidas con resumen y consentimiento. La disponibilidad se confirma por WhatsApp; no hay conexión a calendario ni reservas automáticas.

`index.html` también funciona desde archivo local con sus activos. La maqueta Canvas es conceptual e interactiva; no representa planos aprobados.
