# Construhogar Ingeniería Civil

Sitio de Construhogar: construcción, remodelación y servicios locativos. Ubicación informada: Marinilla, Antioquia · Carrera 34.

La maqueta y las imágenes son conceptuales. La agenda prepara una solicitud de fecha y hora por WhatsApp; no comprueba disponibilidad ni confirma citas.

El sitio puede abrirse directamente desde index.html con la carpeta assets intacta. El script fuente se conserva en assets/js/site.js y está integrado en index.html para compatibilidad local; al editarlo, sincronizar ambas copias.

El despliegue provisional mantiene noindex hasta confirmar el dominio final.
